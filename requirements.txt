# TALA runtime dependencies.
#
# Kept deliberately lean: the target is Streamlit Community Cloud, where the
# container has ~1 GB RAM and a shared CPU, so every wheel here is paid for in
# both build time and resident memory. Upper bounds are pinned so a surprise
# major release cannot slow or break a rebuild.
#
# Deliberately NOT here:
#   spacy / en_core_web_sm  — ~150 MB for POS tagging only, and the pinned model
#                             (3.7.1) was incompatible with the spacy version pip
#                             resolved, so it silently failed to load in
#                             production. Replaced by NLTK's averaged-perceptron
#                             tagger; see core/nlp.py.
#   geodatasets             — was downloading Natural Earth at runtime; the PH
#                             boundary is now vendored as data/ph_land.geojson.
#   seaborn                 — imported nowhere.

# --- core ---
