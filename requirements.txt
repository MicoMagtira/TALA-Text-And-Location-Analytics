# TALA runtime dependencies.
#
# Kept deliberately lean: the target is Streamlit Community Cloud, where the
# container has ~1 GB RAM and a shared CPU, so every wheel here is paid for in
# both build time and resident memory. Upper bounds are pinned so a surprise
# major release cannot slow or break a rebuild.
#
# Deliberately NOT here:
#   spacy / en_core_web_sm  — ~150 MB for POS tagging only, and the pinned model
#                             (3.7.1) was incompatible with the spacy version pip
#                             resolved, so it silently failed to load in
#                             production. Replaced by NLTK's averaged-perceptron
#                             tagger; see core/nlp.py.
#   geodatasets             — was downloading Natural Earth at runtime; the PH
#                             boundary is now vendored as data/ph_land.geojson.
#   seaborn                 — imported nowhere.
#   wordcloud, nrclex,      — the place-first redesign (see docs/PLAN_PANEL.md) dropped
#   rake-nltk, textstat,      the word-cloud, NRC emotion, RAKE keyword and readability
#   nltk                      methods, so nothing imports them any more. Lighter wheels
#                             and a smaller container footprint; core/nlp.py keeps only
#                             VADER + TF-IDF K-Means.
#   matplotlib, networkx    — matplotlib only served the word-cloud colormaps and the
#                             static figure helpers (removed); networkx was imported
#                             nowhere. Charts are Plotly, maps are pydeck.

# --- core ---
streamlit>=1.60,<2  # st.html(..., unsafe_allow_javascript=True) powers audio/splash controllers
pandas>=2.0,<3
numpy>=1.26,<3
pyarrow>=15.0            # Parquet reader for the bundled dataset

# --- charting ---
plotly>=5.20,<7

# --- text analytics ---
scikit-learn>=1.4,<2
vaderSentiment>=3.3.2

# --- geospatial ---
# These wheels bundle their own native libraries (shapely->GEOS, pyproj->PROJ,
# pyogrio->GDAL), which is why packages.txt no longer installs libgeos-dev /
# libproj-dev / libgdal-dev. Those apt packages pulled hundreds of megabytes on
# every rebuild to duplicate what pip already provides.
geopandas>=0.14,<2
shapely>=2.0,<3
pyproj>=3.6,<4
pyogrio>=0.8            # geopandas' default IO engine; ships GDAL in the wheel
pydeck>=0.9,<1          # GPU maps via st.pydeck_chart (click selection); replaced folium

# --- file upload support ---
openpyxl>=3.1            # pandas.read_excel engine for user-uploaded .xlsx
